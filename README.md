# Python Debug Practice

작은 Python 예제로 오류를 재현하고 해결 방법을 기록하는 연습 저장소입니다.
현재 코드에는 학습용 오류가 의도적으로 포함되어 있습니다.

## 실행 환경

- Python 3
- 추가 패키지 없음

## 실행 방법

```bash
python main.py
```

Windows에서 위 명령이 작동하지 않으면 `py main.py`를 사용합니다.

## 현재 동작

`[10, 20, 30]`의 평균은 `20.0`으로 출력됩니다.

하지만 빈 목록 `[]`을 전달하면 다음 오류가 발생합니다.

```text
ZeroDivisionError: division by zero
```

## 원하는 동작

빈 목록에는 계산할 평균이 없으므로, 프로그램이 중단되는 대신
`None`을 반환하도록 수정하고 싶습니다.

## 토론할 질문

- 빈 목록에서 오류가 발생하는 이유는 무엇인가요?
- 빈 목록일 때만 `None`을 반환하려면 어떻게 수정하면 되나요?
